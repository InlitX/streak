Streak 是一款尊重你的习惯打卡工具。随心创建任意数量的习惯，一键完成记录，并通过 GitHub 风格的活动网格、连续天数计数器和统计面板查看你的进度。它快速、离线，让人感到平静而非压力。

完全属于你。无需账号、无订阅、无广告、无追踪。每一个习惯和设置都保存在你的设备上，源代码完全开放。

✅ 打卡
• 在主屏幕、小组件或提醒通知中一键记录
• 三种习惯类型：普通、戒除（含复发）和数量型（自定义单位与每日目标）
• 清单可把一个习惯拆成若干步骤
• 灵活的周期：每天、每周或每月 X 次、指定星期几，或每 N 天
• 点按任意一天补记过去，连续天数会自动跟上
• 每日笔记可附照片，另有假期模式与每周休息日

🎯 专注
• 计时器可自由使用，也可绑定习惯与其目标
• 番茄钟轮次、三种表盘样式与舒缓场景
• 内置音效，也可使用自己的音乐和照片
• 每日专注目标与全部会话历史

📊 进度
• 按周、月或年查看活动网格，另有月历
• 每月完成次数、连续天数走势，以及你最稳定的时段
• 基于近期坚持度的习惯强度
• 可分享的精美进度卡片

🎨 个性化
• Classic 与 Minimal 两种风格
• 极简图标或任意 emoji，以及自定义强调色
• 浅色与深色主题，五种背景，包含纯黑 OLED
• 分类、重新排序、封面照片、个人资料名称与头像

💾 你的数据
• 可从 Loop Habit Tracker、HabitKit、Habitica、HabitBull 或普通 CSV 导入
• 以单个文件备份与恢复，并支持自动备份
• PIN 或指纹应用锁
• 四个主屏幕小组件：习惯、今天、统计与活动网格
• 归档习惯而不丢失历史记录
• 完全离线

🔒 隐私
Streak 没有任何分析工具、广告 SDK 或网络后端。应用绝不会将你的数据发送到任何地方，数据始终保留在你的设备上。唯一的对外操作是你自己选择打开的链接。
