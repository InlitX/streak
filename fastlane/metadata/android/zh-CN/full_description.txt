Streak 是一款尊重你的习惯打卡工具。随心创建任意数量的习惯，一键完成记录，并通过 GitHub 风格的活动网格、连续天数计数器和统计面板查看你的进度。它快速、离线，让人感到平静而非压力。

完全属于你。无需账号、无订阅、无广告、无追踪。每一个习惯和设置都保存在你的设备上，源代码完全开放。

打卡
* 主屏幕一键记录
* 每日、每周和每月目标
* 当前连续天数与最佳连续天数计数器
* 基于近期坚持度的习惯“强度”

可视化
* GitHub 风格活动网格（周 / 月 / 年）
* 含趋势与总计的统计面板
* 可分享的精美进度卡片

个性化
* 极简图标包与 emoji 支持
* 自定义强调色与完整取色器
* 浅色 / 深色主题与可选背景
* 分类、重新排序、个人资料名称与头像

数据与平台
* 可在所选日期为每个习惯设置提醒
* 以便携 JSON 文件备份和恢复
* 三个主屏幕小组件
* 完全离线

隐私
Streak 没有任何分析工具、广告 SDK 或网络后端。应用绝不会将你的数据发送到任何地方，数据始终保留在你的设备上。唯一的对外操作是你自己选择打开的链接。
